# Kế hoạch Thiệu 2026–2042 (app Android)
- `Thieu_2030_2045.html`: toàn bộ chương trình (một file).
- Quy trình GitHub Actions (`.github/workflows/thieu_2030_2045.yml`) chép file này thành `www/index.html`, đóng gói bằng Capacitor và build `app-debug.apk`.
- Cơ sở dữ liệu (`data.json`) tự tạo trong bộ nhớ app lần đầu mở, kèm `data.backup.json`.
- Tải APK: tab Actions → lần chạy mới nhất → mục Artifacts → Thieu_2030_2045-apk.
